# Stack

in this harness refers to the commands below *by name* rather than by their
literal text, so switching from Postgres to MongoDB, or Next.js to plain React,
or Vercel to Railway, means editing this file and nothing else.

Run `/stack <what they told you to use>` to fill this in.
